# Роял Студія Краси — сайт салону краси

Односторінковий статичний сайт салону краси **«Роял Студія Краси»** в Тернополі.
Сайт зроблений без фреймворків, збірки та npm: один `index.html` з внутрішнім CSS
і мінімальним JavaScript. Готовий до публікації на GitHub Pages.

Мова сайту — українська. Дизайн: глибокий матовий зелений з золотом.

## Структура

```
royal-studio/
├── index.html                      ← весь сайт: розмітка, стилі, скрипт
├── README.md                       ← ця інструкція
└── assets/
    ├── emblem.png                  ← емблема логотипа
    └── GreatVibes-Regular.ttf      ← self-hosted шрифт для першого екрана
```

Cormorant Garamond (500, 600) та Inter (400, 500, 600) підключаються через
Google Fonts. Great Vibes лежить локально в `assets/`, тому від зовнішнього
сервера не залежить.

## Що де редагувати

| Що змінити | Де |
| --- | --- |
| Адреса, телефон, графік, Instagram, магазин | Секція `#contacts` у `index.html` |
| Ціни та назви послуг | Секція `#prices` — статичні рядки `<li class="price-row">` |
| Майстри: імена, ролі, фото | Секція `#masters` — картки `.master-card` |
| Відгуки | Секція `#reviews` — картки `.review-card` |
| Кольори бренду | CSS-змінні в `:root` на початку `<style>` |
| Фото | Плейсхолдери `[ФОТО САЛОНУ]`, `[ФОТО]`, `[МАНІКЮР]` тощо — TODO-коментарі поруч |
| Карта | Блок `[КАРТА GOOGLE MAPS]` — у коментарі є приклад `<iframe>` |
| Адреса сайту в Open Graph | `og:url` у `<head>` (замініть `USERNAME`) |

Усі місця для заповнення позначені коментарями `<!-- TODO: ... -->`.
Контакти, ціни, майстри й кольори також перелічені в коментарі на початку `index.html`.

### Як замінити фото

1. Покладіть зображення в `assets/` (наприклад, `assets/salon.jpg`).
2. Замініть блок-плейсхолдер на `<img>` з `alt`:

```html
<img src="assets/salon.jpg" alt="Салон «Роял Студія Краси» в Тернополі">
```

Для карток майстрів і робіт у TODO-коментарях є готові приклади розмітки.
Якщо фото ще немає — залишайте плейсхолдери, вони не ламають верстку.

## Локальний перегляд

Просто відкрийте `index.html` у браузері — сайт працює без сервера.
Для перевірки на телефоні в тій самій Wi-Fi мережі можна запустити будь-який
статичний сервер у папці проєкту, наприклад:

```powershell
npx serve .
```

або відкрити файл напряму.

## Публікація на GitHub Pages

**Статус: сайт ще не опубліковано.** На цій машині немає GitHub CLI (`gh`),
тому репозиторій і GitHub Pages треба створити вручну.

1. Створіть публічний репозиторій `royal-studio` на github.com
   (без README, без .gitignore — вони вже є локально).
2. У папці `royal-studio` додайте remote і запуште гілку `main`:

   ```powershell
   git remote add origin https://github.com/USERNAME/royal-studio.git
   git push -u origin main
   ```

3. У репозиторії відкрийте **Settings → Pages**.
4. У полі **Source** виберіть **Deploy from a branch**.
5. Виберіть гілку **main** і папку **/ (root)**, натисніть **Save**.
6. Через 1–2 хвилини сайт буде доступний за адресою:

   ```
   https://USERNAME.github.io/royal-studio/
   ```

7. Замініть `USERNAME` у `og:url` в `index.html` на свій нік GitHub,
   зробіть commit і push.

Оновлення сайту після редагування:

```powershell
git add index.html
git commit -m "Оновлення сайту"
git push
```

GitHub Pages перебудує сторінку автоматично за 1–2 хвилини.

## Плейсхолдери, які треба заповнити

- `[ФОТО САЛОНУ]` — фото в арці на першому екрані
- `[ФОТО]` × 6 — фото майстрів
- `[Ім’я майстра]` × 6 — імена майстрів
- `[МАНІКЮР]`, `[ВІЇ]`, `[ВОЛОССЯ]`, `[БРОВИ]`, `[ПЕДИКЮР]`, `[ДИЗАЙН НІГТІВ]` — фото робіт
- `[ВІДГУК КЛІЄНТА]` × 6 — тексти відгуків
- `[Ім’я клієнта]` × 6 — імена клієнтів
- `[ГОДИНИ РОБОТИ]` — графік роботи салону
- `[КАРТА GOOGLE MAPS]` — вставити `<iframe>` Google Maps
- `USERNAME` в `og:url` — нік GitHub або власний домен
- `og:image` — за бажанням, зображення 1200×630 для прев’ю в соцмережах
